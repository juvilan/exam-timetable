# exam-timetable

> ⚠️ **이건 운영 중인 시험 시간표 스케줄러가 아니다.**
> 학교에서 실제로 쓰는 웹앱은 `~/Projects/school-tools/exam-scheduler-app/`이며
> 라이브 주소는 **https://examtime.duckdns.org** 이다.
> 이 저장소는 Google Apps Script 기반의 별개 실험 프로젝트다.

시험 일정/시간표 관련 도구(앱) 프로젝트입니다.

## 목적

- 시험 시간표/일정을 관리하고, 제약 조건에 맞춰 편성 작업을 지원합니다.

## 실행

이 레포는 프론트엔드(React/Vite) 기반으로 구성되어 있습니다. 실제 실행 명령은 `package.json`의 scripts를 기준으로 합니다.

```bash
npm install
npm run dev
```

## 메모

- 상세 사용법/입력 포맷/제약 조건은 프로젝트 진행에 맞춰 여기에 링크로 보강합니다.
